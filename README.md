# 은하 열차 일지 — v2.3 우주 항해 창밖 (중간 저장본)

## 이번 수정

《별빛 항해일지》의 `src/Cabin.tsx`, `src/main.tsx`를 확인하고, **항해 중에는 우주가 보이고 목적지 풍경은 도착한 후 나타나는 전환 원칙**과 1·3·8시간별 항해 구간 순서를 적용했습니다.

- 평상시(아직 항해하지 않을 때) 전망 객실 창밖: 별과 성운이 천천히 흘러가는 Canvas 우주. 목적지 후보를 눌러도 창밖은 바뀌지 않습니다.
- 항해 중: 실시간 진행률에 따라 `출항의 빛 → 성운 구간 → 별의 바다 → 오로라 항로 → 떠다니는 섬 → 목적지 접근` 중 해당 항로 길이에 맞는 구간을 지납니다. 별빛이 시차를 두고 흘러가고, 혜성·빛의 띠·떠다니는 섬·멀리 지나는 물체가 등장합니다.
- 마지막 접근 구간: 행성이 천천히 커지지만, 실제 목적지 지형과 현지 기후는 보여주지 않습니다.
- 실제 시간이 지나 도착했을 때: 역 접근 애니메이션(약 3.3초) 뒤 플랫폼과 행성의 고유 Canvas 자연풍경을 보여줍니다. 이미 도착한 항해를 다시 열 때는 정차 상태로 바로 복원합니다.
- 기존 6개 목적지, 행성 2곳 선택, 1·3·8시간 항해, 도착 날씨 추첨, 수정 씨앗 8종, 지역 상호작용, 도감 기록과 저장 키는 변경하지 않았습니다.
- 하차 풍경과 도감의 Canvas 원본은 변경하지 않았습니다.

## 주요 파일

- `src/VoyageSky.tsx`: **신규** 독립적인 이동 중 Canvas 우주 렌더러, 항해 구간 결정 함수.
- `src/Cabin.tsx`: 항해 중에는 `VoyageSky`, 도착 후에는 기존 `Sky`를 사용하도록 전환.
- `src/main.tsx`: 목적지 선택과 창밖 렌더링을 분리, 항해 진행률을 스테이지에 반영, 도착 접근 순서 복구.
- `src/ScenicViewer.tsx`: 큰 화면에서도 항해 중에는 같은 `VoyageSky`를 사용.
