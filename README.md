# 은하 열차 일지 · v1.3

소녀와 고양이가 함께하는 은하 전망 열차. React 19 + TypeScript + Vite.

## 지금 구현된 내용
- 앉아 있는 소녀와 꼬리를 살랑이는 고양이
- 은하 성운과 유리도시 야경, 움직이는 별과 혜성
- 수동 정차 시뮬레이션: 역 접근 → 정차 → 하차 → 재승차 → 다음 항로
- 라일락 성운역과 유리도시 중앙역의 작은 플랫폼 및 가로등
- 풍경 감상 모드

## 실행
```bash
npm install
npm run dev
npm run build
```

## 앞으로 추가할 기능
자동 정차·시간 연동, 씨수정 재배 및 영양제, 수집·상점·도감·저장 시스템.

이 프로젝트는 《별빛 항해일지》와 별개이며, 현재는 시연용 v1.3입니다.
