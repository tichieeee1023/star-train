# 은하 열차 일지 v2.9 — 항해 중 특별 이벤트

《별빛 항해일지》의 SceneDialogue처럼 한 장면 안에서 **한 줄씩 이전/다음으로 넘기는 대화**를 사용합니다. 도착·지역 발견 대화는 더 이상 화면 아래에 전체 줄거리를 쌓지 않습니다.


## v2.9 새 기능 (v2.8 기반)

- **랜덤 창밖 이벤트 6종**: 별똥별 소나기, 혜성의 인사, 먼 역의 신호, 별고래의 노래, 떠오르는 등불, 오로라 커튼. 실시간 Canvas 연출과 각 2종의 소녀·고양이 대사를 추가했습니다.
- **발생 횟수**: 1시간 항해 1회, 3시간 2회, 8시간 4회. 항해 ID를 통해 예정 시각과 종류가 정해지므로 새로고침해도 변경되지 않습니다.
- **이벤트 참여 보상**: 이벤트당 코인 +1~3, 마음 +1~2. 일부 별똥별·혜성·신호 이벤트는 작은 별빛 영양액 1개를 추가 지급합니다. 동일 이벤트의 중복 보상은 불가합니다.
- **놓친 이벤트**: 앱을 닫았거나 실시간 연출을 지나쳤어도 항해 화면의 `창밖의 특별한 순간`에서 대화를 보고 보상을 받을 수 있습니다. 도착 후에도 **다음 항로를 출발하기 전까지** 확인 가능합니다. 지나간 이벤트의 Canvas 연출은 재생하지 않으며 대화와 보상만 제공합니다.
- **차장 이야기 확장**: 기존 3편에 구간별 이야기 6편 추가. 간식 카트에는 무작위 **오늘의 추천 간식(40% 할인)** 1종이 포함되며, 나머지는 기존 20% 할인입니다. 구매 제한은 품목당 3개로 유지됩니다.
- **기존 기록 유지**: 저장 키 `star-train:crystals:v1`, 게임 스키마 버전 1, 기존 수정·도감·마음·간식 기록을 변경하지 않았습니다. 이벤트 수령 여부는 기존 `life.events` 배열에 저장합니다.
- **PWA**: 서비스 워커 캐시 `v2.9.0`. 기존 앱을 설치했다면 재접속 시 갱신을 시도합니다.

### 검증

TypeScript/TSX 전체 구문 검사 통과. 1·3·8시간의 결정적 이벤트 스케줄, 보상 중복 방지, 도착 후 미수령 이벤트 회수, 차장 추천 간식 할인 로직 테스트 통과. Canvas의 6종 이벤트 렌더링 테스트 통과. **정식 `npm run build`와 실제 브라우저 통합 테스트는 미완료**: 검사 환경에서 npm 외부 패키지 다운로드가 DNS 오류로 실패했습니다. 인터넷이 가능한 개발 환경에서 `npm ci && npm run build`를 실행해 주세요.

## 이번 버전

- **별빛 코인**: 1·3·8시간 항해 완료 각각 5·12·29코인. 희귀 목적지 +8, 처음 방문한 행성 +7, 새로 만난 기후 조합 +3, 지역 행동 +3, 수정 완성 등급별 4~10, 차장 첫 인사 +2, 하루 한 번 상점 방문 +5.
- **8종 간식**: 상시 구매 6종 + 방문 차장만 파는 2종. 구매·보유·함께 먹기 분리.
- **차장 방문**: 출항 시점에 방문 여부와 시각을 저장. 1시간 55%, 3시간 80%, 8시간 확정. 카트에 상시 간식 4종 + 차장 한정 2종. 카트 가격은 20% 할인, 품목당 최대 3개 구매.
- **대화**: 항해 단계에 따라 대화가 바뀌는 선실 말풍선. 간식 종류별 2편씩 대화, 차장 3편, 기존 도착·상호작용 대화는 한 화면 안에서 넘김.
- **특별 CG 3종**: 밤하늘 코코아, 달빛 생선 타르트, 은하 도시락을 함께 먹으면 각각 선실 그림과 대화 해금. 상점의 '간식으로 남긴 추억'에 영구 기록, 재감상 가능.
- **기존 기록 호환**: `star-train:crystals:v1` 저장 키와 게임 버전 유지. 기존 저장에 `life` 필드가 없는 경우 빈 지갑과 기본 상점 기록을 추가하며 나머지 기록 보존.
- **PWA**: 서비스 워커 캐시 버전은 이후 버전에서 갱신되었습니다. 이 ZIP은 GitHub/Vercel에 **배포하지 않음**.

## 조작

1. 하단 `간식 상점` 탭 → 하루 보상 받기 또는 간식 구매.
2. 상점에서 `함께 먹기` → 선실 화면의 한 줄씩 넘기는 대화. 특별 간식은 CG 표시.
3. 항해 중 차장 이벤트가 발생하면 카트 안내가 표시되고 차장과 대화 가능.
4. 해금된 CG는 상점 하단 추억 항목에서 다시 볼 수 있음.

## 검증과 한계

- TypeScript/TSX 구문 검사, 타입 진단용 최소 React/Vite 스텁 검사 통과. 이는 **정식 React/Vite 빌드 검사에 해당하지 않음**.
- 순수 게임 로직 검사: 코인 중복 적립 방지, 일일 보상, 구매·사용, 재고 제한, 차장 일정, 특별 CG 해금, 옛 저장 데이터 복원 통과.
- 브라우저에서 소스 컴포넌트 기준 정적 UI 렌더링: 360/390/540px에서 가로 넘침 없음. 대화 패널 높이 약 134~140px.
- `npm ci`가 외부 패키지 다운로드를 완료하지 못해 정식 `npm run build`는 검증 불가. 실제 기기에서의 종합 테스트 및 서비스 워커 갱신 테스트는 추후 필요.

## 실행

npm ci

## v2.6 변경 (선실 돌보기)

1. **선실 그림 보호**: 대화창이 그림 위에 겹치지 않고 그림 바로 아래(`.cabin-talk`)에 놓입니다. 소녀·가방·고양이·컵이 항상 보입니다.
2. **선실 돌보기(항해 중 할 거리)**: 열차 화면에서 고양이 쓰다듬기(쿨타임 15분, 마음 +1), 소녀와 이야기(30분, +2), 간식 나눠 먹기(+2~5, 상점의 '함께 먹기')로 **마음**을 쌓습니다. 마음 8단계마다 보상(코인·영양액, Lv.3·5·7은 수정 씨앗 선물)과 새 대화가 열리고, 해금한 대화는 '마음 대화 기록'에서 다시 들을 수 있습니다. 쓰다듬으면 선실 그림에 하트가 떠오릅니다.
3. **씨앗 보장**: 첫 항해는 항상 수정 씨앗을 받고, 연속 두 번 놓치면 세 번째는 보장됩니다(`seedMisses`). 평소 확률(1시간 40%·3시간 60%·8시간 확정)은 그대로입니다.

저장 호환: 기존 저장에는 `life.bond`와 `seedMisses`만 추가되며 나머지는 그대로입니다. 서비스 워커 캐시 `v2.6.0`.

검증: 브라우저(Chromium)에서 앱 전체를 번들해 실행하며 확인했습니다. 쿨타임, 보상 중복 방지, 새로고침 후 유지, 간식 연동, 옛 저장 호환, 첫 항해 씨앗 보장 통과. 정식 `npm run build`(타입 검사 포함)는 이 환경에 패키지가 없어 검증하지 못했습니다.
