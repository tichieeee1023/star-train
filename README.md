# 은하 열차 일지 v2.2 — 탐험과 풍경 도감

《별빛 항해일지》의 항해·도감 구조를 은하 열차에 적용한 버전입니다.

- 일반 목적지는 무작위 두 곳만 제시하고, 항해 시간은 1·3·8시간 중 선택합니다.
- 시간에 따라 노을·새벽·한밤으로 달라지며, 실제 도착 시 지역별 기후가 무작위로 결정됩니다.
- 희귀 항로는 일반 목적지에서 항해 후 발견할 수 있습니다.
- 도착하면 행성 카드(`sceneCards`), 시간대별 사진(`sceneShots`), 특별 기후 사진(`atmosphereShots`)이 자동 기록됩니다.
- 미발견 시간대와 기후는 잠금 상태입니다. 실제로 발견한 풍경만 도감에서 다시 볼 수 있습니다.
- 풍경·수정·작은 발견 도감과 미니 별자리 지도를 제공합니다.
- 수정 8종 재배, 희귀도별 반짝임, 색 변이, 소녀와 우주고양이의 대화를 유지합니다.
- 이전 저장 키 `star-train:crystals:v1`을 유지하고 v2.1 풍경 기록도 복원합니다.
