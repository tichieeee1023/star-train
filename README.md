# 은하 열차 일지 — v2.0 (수정 도감 업데이트)

우주 열차의 6개 풍경을 Canvas 2D로 감상하고, 역에 도착해 소녀와 우주고양이의 대화를 듣고, 지역별 상호작용과 수정 씨앗 재배를 즐기는 작은 방치형 게임입니다.

## v2.0 추가 사항

- **수정 8종에 각각 다른 결정 실루엣**: 별물방울, 라일락, 청람, 서리별, 황혼, 궤도, 오로라, 유성 심장석
- **희귀도 4단계**: 보통(common), 특별(special), 희귀(rare), 신비(mystic)
- **희귀도별 반짝임 차이**: 작은 빛점 → 십자 섬광 → 굴절광 → 맥동하는 빛핵과 공전 입자
- **성장도별 광채**: 씨앗 단계부터 완성 단계까지 이펙트 강도가 달라집니다.
- **색깔 변이와 재배 기록 유지**: 기존 `star-train:crystals:v1` 저장 키와 수정 ID를 변경하지 않았습니다.
- 움직임 최소화 설정(`prefers-reduced-motion`)을 사용하면 반복 애니메이션을 끕니다.

## 항로와 재배

- 일반 항로 1시간 40%, 3시간 60%, 8시간 100% 씨앗 발견 확률. 희귀 항로는 시간과 무관하게 100%입니다.
- 출발·도착 시간, 보상, 씨앗, 성장, 도감은 브라우저 로컬 저장소에 보관합니다.
- 6개 지역, 12개 상호작용, 18종 도착 대화, 36종 상호작용 대화를 포함합니다.
- 성장: 씨앗 → 결정 성장 → 결정 분화 → 완성. 별빛과 관리, 영양액, 조명에 따라 색 변이가 결정됩니다.
- 기기·브라우저가 다르면 저장 기록은 자동 동기화되지 않습니다.

## 실행

```bash
npm ci
npm run dev
npm run build
```

Vite + React + TypeScript. `public/art/galaxy-cabin.svg`는 객실·캐릭터용 정적 에셋이고, 바깥 풍경은 `src/CanvasPaint.ts`에서 그립니다.
